# MA429 Cybersecurity Assignments

This repository contains my C++ solutions for the MA429 assignment.

## Files

The `solutions` folder contains the programs for the assignment:

1. `01_password_panel_flipping.cpp`
2. `02_interactive_bitwise_operations.cpp`
3. `03_restore_string_from_trigrams.cpp`
4. `04_metropolis_network_xor.cpp`
5. `05_spy_syndrome_decoding.cpp`
6. `06_sherlock_adjacent_operations.cpp`
7. `07_xenons_attack_on_the_gangs.cpp`
8. `08_dynamic_bipartite_graph.cpp`
9. `09_virus_contacts_rollback_dsu.cpp`
10. `10_interactive_hash_collision.cpp`

The `SUBMISSION_REPORT.pdf` file has the explanations and analysis for the solutions.

## How to compile

For a normal C++ file, open a terminal in the `solutions` folder and run:

```bash
g++ -std=c++17 filename.cpp -o program
./program
```

Replace `filename.cpp` with the file you want to compile.

Problems 2 and 10 are interactive, so they need to be run with their respective interactive judge. They will not work like normal programs with a regular input file.
